Projects

A collection of projects I have created, worked on, or am currently developing.

Vampa in Python

The first Vampa cybersecurity toolkit I made is written in Python.

The first toolkit I made was called Vampa, and it was coded in Python. It mainly provided basic functionality such as port scanning, tracerouting, pinging, DDoS testing, and encrypting files with a password.

(I still have the project, but I gave up on the toolkit because I wanted to focus on Go rather than Python.)

Vampa in Go

The second Vampa cybersecurity toolkit I made is written in Go.

The second toolkit I made was also named Vampa. I decided to retry the project, but this time in Go. It brings together different security, reconnaissance, information-gathering, networking, web, system, CTF, OSINT, and reporting functionality into one toolkit. It also includes file and directory encryption, C2 communication, API manipulation, and many checking and lookup tools.

(The project is still private and under development.)

Obfuscated Encrypted Go Payload Loader with Anti-Debugging and Anti-Analysis

It is an obfuscated, encrypted Go payload loader that hides a payload inside a PNG, checks whether the program has been modified or debugged, decrypts the hidden payload, and then executes it. It also uses anti-analysis techniques to make reverse engineering harder.

(To be honest, the project is in a rough state. The main issues are that the loader is fragile, the integrity check can break after modifying the executable, it requires Go to run the payload, and the anti-analysis and payload-extraction methods are unreliable.)

Ovify Health and Security

Bash system audit/information scripts

There are two Bash scripts. The first displays basic Linux system information, such as the user, hardware, battery, and disk usage, and checks which security tools are installed. The second is a more organized system audit that checks system, hardware, disk, battery, network connections, installed security tools, and basic system health. Both work by running standard Linux commands and formatting their results in the terminal.

(The project is complete, but it still needs to be polished.)

Secrecy

(The project is mainly a cheatsheet that I barely use. I will not publish it because there is no need. Moreover, the Bash script is poorly organized and too long, which makes it difficult to modify or read.)
