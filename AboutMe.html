Vampa

Vampa is my own cybersecurity toolkit, which I actively develop in Go.

It brings together different security, reconnaissance, information-gathering, system, networking, web, and reporting capabilities into a single toolkit.

Vampa currently includes modules for DNS enumeration, IP lookups, email and username lookups, phone lookups, encryption and hashing, web reconnaissance, crawling, technology fingerprinting, HTTP headers, SSL information, URL analysis, subdomain discovery, system information, process information, services, storage, memory, networking, logs, security checks, and reporting.

The project also contains CTF and OSINT reporting functionality, wordlists, and a separate VampaC2 component.
